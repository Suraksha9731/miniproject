# Digital Clock with FPGA Implementation using Verilog

## Mini Project

This project implements a 12-hour digital clock using Verilog HDL on FPGA.

## Features
- Real-time clock display
- FPGA implementation
- Verilog HDL design
- Seven-segment display output
- Accurate timing using clock divider

## Technologies Used
- Verilog HDL
- Xilinx Vivado / ISE
- FPGA Board
- Seven Segment Display
